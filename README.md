# 에브리타임 시간표 배경화면 만들기

에브리타임에서 다운로드한 시간표 이미지를 스마트폰 배경화면으로 변환해주는 웹 도구입니다.

## 기능

- 시간표 이미지 업로드 (클릭 / 드래그앤드롭)
- 다크모드 / 라이트모드 배경 선택
- 시간표 위치 조절 (상단 / 중앙 / 하단)
- 다양한 기기 해상도 프리셋 (iPhone, Galaxy 등) + 직접 입력
- 시간표 크기 조절 (30% ~ 100%)
- PNG 이미지 다운로드

## 지원 기기

| 기기 | 해상도 |
|------|--------|
| iPhone 16 Pro | 1206 x 2622 |
| iPhone 16 Pro Max | 1320 x 2868 |
| iPhone 15 / 16 | 1179 x 2556 |
| iPhone 14 Pro | 1179 x 2556 |
| iPhone 14 Pro Max | 1290 x 2796 |
| iPhone 13 / 14 | 1170 x 2532 |
| iPhone SE | 750 x 1334 |
| Galaxy S25 / S24 | 1080 x 2340 |
| Galaxy S25 Ultra | 1440 x 3120 |
| Galaxy S24 Ultra | 1440 x 3088 |
| Galaxy A시리즈 | 1080 x 2400 |

직접 입력으로 원하는 해상도를 지정할 수도 있습니다.

## 사용법

1. 에브리타임 앱에서 시간표를 이미지로 저장
2. 웹사이트에 접속하여 시간표 이미지를 업로드
3. 다크/라이트 모드, 위치, 기기, 크기를 설정
4. 생성하기 버튼 클릭
5. 다운로드 버튼으로 배경화면 저장

## 기술 스택

- HTML5 / CSS3 / JavaScript (바닐라)
- Canvas API
- GitHub Pages

## 개인정보

모든 이미지 처리는 브라우저에서 이루어지며, 서버로 전송되지 않습니다.
